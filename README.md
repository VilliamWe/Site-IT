# Site IT

Учебный frontend-проект: адаптивный лендинг образовательной IT-платформы.

Проект демонстрирует работу с современной frontend-сборкой, компонентной организацией стилей, адаптивной вёрсткой и интерактивными элементами интерфейса.

## Дизайн

Макет интерфейса в Figma:  
[Открыть IT SITE в Figma](https://www.figma.com/design/PyEkAzWYiGcQ9FP0APRH84/IT-SITE?m=auto&t=nRFfsJfnbknwuHpj-1)

## Возможности

- адаптивная вёрстка основных секций лендинга;
- мобильное меню;
- слайдеры на Swiper;
- компонентная структура SCSS;
- сборка проекта через Vite;
- интерактивные элементы на JavaScript.

## Стек

- HTML5
- SCSS
- JavaScript
- Vite
- Swiper

## Структура проекта

- `index.html` — основная разметка страницы;
- `src/scss` — стили проекта;
- `src/js` — JavaScript-логика;
- `src/assets` — исходные ресурсы;
- `public` — публичные статические файлы.

## Установка и запуск

```bash
npm install
npm run dev
```

## Production-сборка

```bash
npm run build
```

## Предпросмотр production-сборки

```bash
npm run preview
```

## Статус

Проект выполнен в учебных целях и используется как часть frontend-портфолио.
